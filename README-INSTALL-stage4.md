## 4. ★상극 — 감점은 그대로, 두 견해를 «재료» 로

교재 107쪽은 「상극이라 흉하다는 말은 무시하라」고 합니다.
그러나 상생을 보는 유파도 있어 **감점 구조를 바꾸지 않고** 두 견해를 AI 에게 전합니다.

```
[★상극을 보는 두 견해 — 한쪽으로 단정하지 말고 함께 전해 주세요]
· 성명학에는 자원오행도 상생으로 이어지는 배열을 좋게 보는 견해가 있습니다.
· 한편 「자원오행은 사주에 필요한 기운을 채우는 것이 본래 목적이므로,
  억지로 상생 배열을 맞출 필요는 없고 상극이라 하여 흠으로 볼 일은 아니다」
  라고 보는 견해도 있습니다. 이름을 짓는 실무에서는 뒤엣것을 따르는 분도 많습니다.
```

★세 경우가 갈립니다.

```
상극이 남음        →  «두 견해» 를 실습니다
④ 예외로 면제됨    →  「보완하는 글자가 만든 것이라 흠으로 보지 않는다」만 (겹치지 않게)
상극이 없음        →  둘 다 안 실습니다 (교훈 BF)
```

## 5. ⚠️ 배점을 바꿨다가 «되돌린» 이력

```
W_FLOW 30 → 10 · W_YONGSIN 40 → 60 으로 바꿔 봤다가 되돌렸습니다.
  까닭 ①  교재 107쪽 「성을 제외한다」를 «흐름에서 성을 빼라» 로 잘못 읽었습니다.
          실제로는 «용신 충족을 어디서 세는가» 입니다.
          상생 흐름은 성-상명자-하명자 순환으로 보는 것이 정석이고,
          지금 코드가 이미 그렇게 하고 있습니다.
  까닭 ②  실측이 역효과였습니다 — 아쉬움 30.9% → 46.0%.
          용신 미충족 시 0점이 되어 오히려 가혹해졌습니다.
          「낮은 점수를 주어 개명을 유도하지 말라」는 교재 취지와 정반대입니다.

★resourceJudge.ts 의 배점 주석에 이 이력을 남겨 두었습니다. 다시 시도하지 마십시오.
```

## 6. 그물이 잡은 것
