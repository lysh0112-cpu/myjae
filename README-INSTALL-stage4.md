## 4. ★상극 — 감점은 그대로, 두 견해를 «재료» 로

교재 107쪽은 「상극이라 흉하다는 말은 무시하라」고 합니다.
그러나 상생을 보는 유파도 있어 **감점 구조를 바꾸지 않고** 두 견해를 AI 에게 전합니다.

```
[★상극을 보는 두 견해 — 한쪽으로 단정하지 말고 함께 전해 주세요]
· 성명학에는 자원오행도 상생으로 이어지는 배열을 좋게 보는 견해가 있습니다.
· 한편 「자원오행은 사주에 필요한 기운을 채우는 것이 본래 목적이므로,
  억지로 상생 배열을 맞출 필요는 없고 상극이라 하여 흠으로 볼 일은 아니다」
  라고 보는 견해도 있습니다. 이름을 짓는 실무에서는 뒤엣것을 따르는 분도 많습니다.
```

★세 경우가 갈립니다.

```
상극이 남음        →  «두 견해» 를 실습니다
④ 예외로 면제됨    →  「보완하는 글자가 만든 것이라 흠으로 보지 않는다」만 (겹치지 않게)
상극이 없음        →  둘 다 안 실습니다 (교훈 BF)
```

## 4-2. ★형제 서열 안내 — 감점 없이 «참고» 로만 (대표님 지시)

120쪽 표는 「첫째 칸 / 둘째 칸」이 «쓸 글자» 인지 «피할 글자» 인지 갈리지 않습니다.
그런데 **불용 목록이 그 애매함을 풀어 줍니다** — 여섯 자가 «한 방향» 입니다.

```
完  맏이가 쓰는 것은 무방하나 차자가 쓰면 형을 극한다
元  맏이가 쓰면 무방하나 차자가 쓰면 불길하다
泰  장자는 무방하나 차자는 삶에 역경이 많고 잔병치레를 겪는다
長  동생이 쓰면 형이 망하고 자신도 좋지 않다
大  동생이 쓰면 형을 극한다
輝  동생이 쓰면 안 좋다
```

★여섯 자 모두 «맏이는 무방 · 동생이 쓰면 문제» 입니다.
즉 표의 「둘째 칸」은 «둘째가 쓸 글자» 가 아니라 **«둘째가 피할 글자»** 로 읽는 것이 맞습니다.
본문의 「동생이 大를 사용하게 되면 … 동생이 첫째를 누를 수 있고」와도 맞습니다.

⚠️ 다만 이것은 «저희 해석» 이라 **감점하지 않고 안내만** 합니다.

### 통변에 나가는 모양

```
[형제 서열에 따라 가려 쓰는 글자 — ★참고로만 전해 주세요]
· 元(원) — 예로부터 «맏이가 쓰면 무방하나 아래 형제가 쓰면 한 번 살펴보라» 고
  전해 오는 글자입니다.

※ 다루는 법
· ★«좋지 않다» 로 단정하지 마시고, 「이런 견해가 전해 온다」 정도로만 담담히 전하세요.
· 형제 순서를 저희가 알지 못하므로 «맞다 / 틀리다» 를 말하지 마세요.
  「해당하신다면 한 번 헤아려 보시라」 는 정도가 알맞습니다.
· 이 한 가지로 이름 전체를 판단하지 마세요. 다섯 관점 가운데 작은 참고입니다.
```

★두 갈래로 갈라 적습니다.

```
불용 목록에 «문장» 으로 실린 여섯 자   방향을 밝혀 적습니다 (맏이는 무방하나…)
120쪽 표에만 있는 열 자                방향을 말하지 않습니다 (순서에 맞추어…)
해당 글자가 없으면                     블록을 «아예» 안 넣습니다 (교훈 BF)
```

⚠️ **원문 사유(「형을 극한다」·「불길하다」)를 그대로 내보내지 않습니다.**
그물이 원문 유출과 단정적 부정어를 검사합니다.

## 5. ⚠️ 배점을 바꿨다가 «되돌린» 이력

```

  까닭 ①  교재 107쪽 「성을 제외한다」를 «흐름에서 성을 빼라» 로 잘못 읽었습니다.
          실제로는 «용신 충족을 어디서 세는가» 입니다.
          상생 흐름은 성-상명자-하명자 순환으로 보는 것이 정석이고,
          지금 코드가 이미 그렇게 하고 있습니다.
  까닭 ②  실측이 역효과였습니다 — 아쉬움 30.9% → 46.0%.
          용신 미충족 시 0점이 되어 오히려 가혹해졌습니다.
          「낮은 점수를 주어 개명을 유도하지 말라」는 교재 취지와 정반대입니다.

★resourceJudge.ts 의 배점 주석에 이 이력을 남겨 두었습니다. 다시 시도하지 마십시오.
```

## 6. 그물이 잡은 것

재료에 「«나쁘다» 로 단정하지 마시고」라고 적었다가 **판정 어휘 검사에 걸렸습니다.**
금지어를 «예시» 로 넣으면 AI 가 그것을 끌어 씁니다. 「흠으로 단정하지 마시고」로 고쳤습니다.
