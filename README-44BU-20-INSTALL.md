★**화면은 「■ 로 시작하는 줄」을 제목으로 봅니다** — 제목 이름을 미리 알 필요가
없어, 새 대목도 **자동으로 카드가 됩니다.** 화면 코드를 크게 고칠 필요가 없었습니다.
