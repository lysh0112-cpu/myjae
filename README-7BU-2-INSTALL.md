## 2. 연재쌤 답 여덟 — 무엇이 어떻게 들어갔나

### ① 🔴 관성과 인성을 «같이» 봅니다 — 제 생각을 뒤집었습니다

```
[연재쌤]  「관성은 ★직책의 의미, 인성은 ★문서나 도장의 의미이니
           ★같이 있어야 좋을 듯」
[제가 하려던 것]  «문» 이면 인성 · 아니면 관성 — ★갈라서 보려 했습니다
[고침]    ⛔ 가르지 «않습니다». ★언제나 둘을 «함께» 보고,
          «문» 에서는 인성 쪽에 무게를 더 둡니다.
```

⚠️ **제가 교재 사례 한 건(「임원은 偏印 결재권」)을 너무 크게 읽었습니다.**
   연재쌤 말씀이 맞습니다 — **직책(관성)이 없는데 도장(인성)만 와도 승진이 아닙니다.**

### ② 🔴 문 — 군인·경찰·소방을 고쳤습니다

```
[연재쌤]  「회사원·공무원·은행원은 맞는 것 같은데
           ★군인은 중령 정도 되어야 한다. 경찰과 소방은 ★온라인을 찾아볼 것」

★찾아보니 «법» 이 대응을 정해 두고 있었습니다 —
   공직자윤리법 시행령   ★중령 = 5급 사무관 = 소방령 = 경정
   공직자윤리법          ★대령 = 4급 서기관 = 총경 = 소방정

⇒ ⇒ ★연재쌤이 말씀하신 «중령» 이 곧 공무원의 «5급 사무관» 이었습니다.
   그러니 경찰·소방도 저절로 정해집니다.
```

```
[전 — 제가 잡은 것]        [후 — 찾은 값]
  경찰  경사 → 경위    ⇒   ★경감 → 경정
  소방  소방장 → 소방위 ⇒  ★소방경 → 소방령
  군인  원사 → 소위     ⇒  ★소령 → 중령
```

⚠️ **제 표가 옛날 값이었던 까닭도 나왔습니다.**

```
「2000년대 이후 ★근속승진 확대로, 관리직(팀장·지구대장)에 보임되지 않는
  ★«실무 경감» 이 늘고 있다」
  — 경감 정원 10,852명인데 2023년 현원 ★25,155명
⇒ 경위·경감은 이제 «결재하는 자리» 가 아닙니다.
  지구대장·경찰서 과장은 ★경정입니다.
```

⇒ **연재쌤이 「찾아볼 것」이라 하신 것이 옳았습니다.** 제가 짐작으로 잡았으면 틀린 채로 갔습니다.

### ③④ 그대로 넣었습니다

```
삼합 무게 올림 · 재생관 넣음 · 자리별 충 씀 · 반안살 씀
⛔ 지살은 ★뺍니다 — 방향(방위) 이야기라 프로그램에 담기 어렵습니다
```

### ⑤ 🔴 비겁은 «겨루는 사람 · 경쟁자»

```
[연재쌤]  「비겁은 ★겨루는 사람, 경쟁자로」
⇒ 교재 190~191쪽의 «이직 신호» 가 아니라 ★«경쟁자» 쪽으로 정해졌습니다.

⛔ 다만 손님 글에 ★«경쟁자» 라는 낱말은 쓰지 않습니다.
   ⇒ 「같은 자리를 바라보는 분이 여럿인 때로 봅니다.
      내가 한 일이 «누구 것인지» 또렷하게 남겨 두십시오」
   ⇒ ★«할 일» 로 옮겨 적습니다. 겁주지 않습니다.
```

### ⑥ 🔴 이직 갈래를 «부르지 않습니다»

```
[연재쌤]  「승진을 물었는데 나가는 자국이 있더라도 ★넣지 말 것」
⇒ PROMO_USE_JOBCHANGE = ★false
⇒ ⛔ 승진운에서 jobChange 를 부르지 마십시오. ★물으신 것만 답합니다.
⇒ 「지금 자리에서 더 버틸지 고민입니다」 라 적으신 분께도
  ★승진 쪽으로만 답합니다 — 「그 뒤에 보셔도 늦지 않습니다」.
```

⚠️ 제가 기초자료에서 **「이 갈래가 제일 값지다」**고 썼던 자리인데, 연재쌤이 **빼라고 하셨습니다.** 그대로 따릅니다.

### ⑦ 🔴 사주 용어 — 한 갈래에 «셋» → ★«하나»

```
[대표님]  「약간 사주용어가 들어가도 무방해… ★과하지만 않다면」
[연재쌤]  「★꼭 필요한 말이 아니면 쓰지 말자」
⇒ 🔴 ★연재쌤이 «한 걸음 더» 줄이셨습니다.
  어림으로 잡았던 ★셋을 ★«하나» 로 내렸습니다.
  ⇒ 한 갈래에 ★한 개까지. 그것도 «그 갈래에 꼭 필요할 때» 만.
  ⇒ ⛔ 넷을 다 채우려 하지 마십시오. ★0개여도 됩니다.
  ⇒ 4번 갈래(응원)는 그대로 ★0개입니다.
```

⚠️ **제가 보여 드린 샘플 통변문은 이 규칙을 넘습니다.** (1번 넷 · 2번 다섯 · 3번 셋)
   ⇒ **다시 쓸 때 줄이겠습니다.**
