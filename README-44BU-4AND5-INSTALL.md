## ★십성 표에 까닭 한 줄 (대표님 지시)

한 화면에 «세 가지 셈» 이 나란히 있습니다.

```
오각형     «점수» + 계절 치환   →  목(비겁) 55%
십성 표    «글자 개수»          →  정재 57.1% · 비견 14.3%
육친 점수  «점수» + 계절 치환   →  비겁 55점
```

⇒ 「목이 55%인데 비견은 14.3%」가 됩니다. 손님이 갸웃하실 자리입니다.

★**십성은 «글자 그대로» 세는 것이 맞습니다.** 십성은 「이 글자가 일간에게
무엇인가」이고, 그것으로 육친(아버지·재물·배우자)을 읽습니다.
계절로 바꿔 세면 **사람이 바뀝니다.**

⇒ **셈은 고치지 않고 까닭만 말합니다.**

```

  "십성은 글자를 있는 그대로 셉니다.
   위 오행 비율은 계절 치환이 들어가 서로 다를 수 있어요."
```

⚠️ 이것은 «전부터» 있던 어긋남입니다(월지 치환이 예전부터 걸려 있었으니까요).
