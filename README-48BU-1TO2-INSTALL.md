## 2. ⚠️⚠️ lib/saju/yongsinNew.ts 를 «왜» 건드렸나

이 파일은 47부 11장 「⛔ 손대지 말 것」입니다. ★20개가 넘는 파일이 기댑니다.

**로직은 한 글자도 안 건드렸습니다.** `export` 한 낱말만 아홉 줄에 붙였습니다.

```
export const ALL              export interface Rel
export function relOf         export type Yukchin5
export const P151_TABLE       export function yukchinOfEl
export function hasInsungRoot export function countGeopjae
export const GYEOK_SANGSIN
```

⚠️ **왜 이렇게 했나** — 교재 151쪽 표를 새 파일에 «옮겨 적으면» 사본이 둘이 됩니다.
   45부 교훈 BQ 「이 표는 사본입니다. 한쪽만 고치지 마십시오」와 똑같은 일이 또 생깁니다.
   ⇒ 부르는 쪽에서 «원본을 그대로» 읽게 했습니다.

✅ **안 바뀐 것을 어떻게 확인했나** — 「오행·용신 그물」 531건이 그대로 통과했습니다.
   판정이 한 톨이라도 바뀌었으면 여기서 걸립니다.

⛔ 이 파일의 **로직**은 여전히 손대지 마십시오.
