### ② 성씨 «흔한 차례» 로 앞에 세웁니다 (인구수 순)

실측 — 「이」 음 한자 19자를 넣어 재 보았습니다.

```

후   ★李 異 伊  二 已 尼 以 尔 弛 而 耳 吏 夷 杝 里 姨 移 貳 飴
     └ 성씨 표의 흔한 차례 ┘ └── 나머지는 예전대로 획수 차례 ──┘
```

**표의 «소리 차례» 는 이미 통계청 인구수 순이었습니다.** 값을 재 보았습니다.

```
앞 다섯   金 → 李 → 朴 → 崔 → 鄭        ★요청하신 순서 그대로
앞 열둘   김 이 박 최 정 강 조 윤 장 임 한 오
```

⇒ **값은 한 글자도 바꾸지 않았습니다.** 대신 두 가지를 더했습니다.

```
① 표 머리에 「이 차례는 통계청 인구수 순」이라는 근거를 «적었습니다»
   ★사람이 이 파일에 새 성씨를 끼워 넣을 때 잣대가 있어야 합니다

      그래서 정규식이 아니라 표를 «직접 불러» 앞 열둘을 맞대어 봅니다
```

⚠️⚠️ **다만 이 «소리 차례» 는 손님 화면에 «보이지 않습니다».**
   표는 소리로 찾는 것이라(「이」를 누르면 이 줄만 옵니다),
   金·李·朴이 «한 목록에 함께» 뜨는 일은 없습니다.
   ★손님 눈에 보이는 것은 «한 소리 안의» 차례입니다 — 「이」 → 李 異 伊.
   그 차례가 이번에 정밀분석 화면까지 «가게 된» 것이 이번 수정의 알맹이입니다.

⚠️ 표에 없는 한자를 **빼지 않습니다** — 뒤로 보낼 뿐입니다 (`surnameRank` = 999).

⚠️ **수량을 재 보니 「189 연 · 186 고유」 였습니다.** 43부 문서의 186 은 «고유» 수이고
   틀리지 않았습니다. 柳·劉(류/유)와 羅(나/라)가 두음법칙 때문에 두 소리에 걸쳐
