```
★3단계-b 를 «대신합니다» — 3단계-b 파일이 전부 들어 있습니다.
  3단계-b 를 아직 안 올리셨으면 이것만 올리시면 됩니다.
  이미 올리셨으면 그 위에 덮어쓰시면 됩니다.

바뀐 파일 9개.  검사 221건 (그대로).
```

---

## 1. 어디에 붙었나

### ① 제목 카드 아래 — 종합 별점

```
"버드나무처럼 유연하게, 풀꽃처럼 따뜻하게 — 류도이라는 이름이 품은 결"
성명학이 이름을 살피는 다섯 갈래의 관점으로 …
─────────────────────────────────────────────
        다섯 관점을 아울러  ★★★★★ 4.5  우수함
```

### ② 각 관점 제목 «아래 줄»

```
一. 음양오행  획수에 담긴 음과 양                          ▼
    ★★★★★ 4.5  우수함
```

⚠️ **같은 줄에 넣지 않았습니다.** 430px 화면에서
「자원오행 한자에 담긴 본래 기운 ★★★★★ 4.5 매우 조화로움」이 줄바꿈되며 지저분해집니다.

### ③ 하단 고지에 한 줄 추가

> 별점은 이름의 좋고 나쁨을 가르는 점수가 아니라, 다섯 관점 가운데
> 어느 쪽을 더 살펴보면 좋을지 가리키는 눈금입니다.

★대표님이 세우신 「좋다/나쁘다 판정하지 않는다」 방침과 별점이 어긋나 보이지 않게
**화면 안에서 스스로 설명하게** 두었습니다.

## 2. 실제로 이렇게 나옵니다

오늘 확인하신 세 이름의 사주로 계산한 결과입니다.

```
══ 류도이 (용신 목 충족 · 경고 0건)
  다섯 관점을 아울러   ★★★★☆ 4.5  우수함
  음양오행     ★★★★☆ 4.5  우수함           (3단)
  발음오행     ★★★★☆ 4.5  우수함           (3단)
  수리오행     ★★★☆·  3.5  보통 · 살펴볼 자리  (3단)
  자원오행     ★★★★★ 5.0  매우 조화로움
  사주와의 만남 ★★★★★ 5.0  매우 조화로움

══ 류해수 (용신 미충족 · 과다 + 구신)
  다섯 관점을 아울러   ★★★··  3.0  참고 · 보완 권장
  자원오행     ★★★★☆ 4.5  우수함              ← 흐름은 좋습니다(水生木)
  사주와의 만남 ★★☆··  2.5  살펴볼 자리가 여럿

══ 용신은 담았으나 나머지가 낮은 경우
  자원오행     ★★☆··  2.5  살펴볼 자리가 여럿
  사주와의 만남 ★★★★·  4.0  좋음               ← 용신 하한이 지킵니다
```

★**류해수** 를 보십시오 — 자원오행은 ★4.5(흐름이 좋음)인데 사주와의 만남은 ★2.5 입니다.
**두 관점이 서로 다른 것을 가리킨다**는 것이 별로 드러납니다. 옛 3단 등급으로는 안 보이던 자리입니다.

## 3. 색과 접근성

```
높은 칸(★4.0~5.0)   진한 금 #c8783c
가운데(★3.5)        옅은 금 #c79a72
낮은 칸(★2.5~3.0)   회갈  #b09a8a     ★붉은 «경고색» 을 쓰지 않습니다
```

⚠️ 낮은 별에 빨강을 쓰면 「나쁨」으로 읽힙니다. 방침과 어긋나므로 **흐린 회갈**로 두었습니다.

별은 `aria-hidden` 이고 옆에 `sr-only` 로 「5점 만점에 4.5점, 우수함」을 읽어 줍니다.
(Tailwind v4 가 있어 `sr-only` 가 동작합니다 — 확인했습니다)

## 4. ⚠️ 알아 두실 것 둘

### ① 음양·발음·수리는 별이 세 가지뿐입니다

```
자원오행 · 사주와의 만남   0~100 정밀     ★2.5 ~ ★5.0 전부 나옵니다
음양 · 발음 · 수리        3단 등급        ★4.5 · ★3.5 · ★3.0 만 나옵니다
```

`좋음→80점 · 보통→52점 · 아쉬움→40점` 으로 옮기기 때문입니다.
**그래서 이 셋은 ★5.0 이 절대 안 나옵니다.**

`precise: false` 로 표시해 두었으니 화면에서 다르게 그리실 수도 있습니다.
정밀하게 하려면 `scoreSuri`·`scoreSound` 를 고쳐야 하고 그건 4단계입니다.

### ② 보관함 다시보기

별점을 `commentary._stars` 안에 함께 저장하고, 되읽을 때 `extractStars()` 로 꺼냅니다.

```
새로 발행한 기록   별이 보입니다
옛 기록           별이 «안 보입니다». 글은 그대로 나옵니다 (안 깨집니다)
```

⚠️ `saveNamingRecord` 의 타입을 넓히지 않고 `commentary` 안에 담았습니다.
타입을 넓히면 `namingRecords.ts` 와 그것을 읽는 보관함·상담사 화면까지 손대야 합니다.

## 8. 되돌리기

별만 빼고 싶으시면 `PerspectiveAccordion` 호출에서 두 prop 을 지우면 됩니다.

```tsx
<PerspectiveAccordion commentary={commentary} />
```

라우트는 계속 `stars` 를 내려보내지만 화면이 안 그리면 아무 일도 일어나지 않습니다.
