## 1. 무엇이 잘못돼 있었나

```
[대표님]  「공망을 ★"빈자리가 있는 날이에요" 로 표현되어 있는데…」

★세 가지가 어긋나 있었습니다 —

① 결혼택일 «요약» 은 「빈자리」, «근거 칸» 은 「공망」
   ⇒ 🔴 한 화면에서 ★같은 것을 «두 말» 로 불렀습니다.

② 「빈자리」 가 ★무슨 뜻인지 «아무 데도 없었습니다»
   ⇒ 손님이 읽고 ★«빈자리가 뭐지» 합니다.
   ⚠️ 「모난다」 · 「부딪힌다」 는 읽으면 아는데, ★「공망」 은 풀어 줘야 압니다.

③ 이사택일 제목 「빈자리를 ★비껴갔어요」
   ⇒ 본문은 「공망은 기운이 비는 자리예요」 라 ★잘 되어 있는데 제목만 «빈자리».
   ⇒ ★«비껴» 가 아니라 «비켜» 가 맞습니다 [대표님].
```

## 2. 고친 것

### ① 결혼택일 — 공망을 쓰고 · 뜻을 풀고 · 왜 피하는지까지

```
[전]  「신부분께 ★빈자리인 날이에요」
[후]  「신부분께 ★공망(기운이 비는 자리)인 날이에요」
      「힘이 실리지 않는 자리라, 큰일을 시작하는 날로는 피합니다.」  ← ★뒷줄
⇒ ★대표님이 주신 문장 그대로입니다.
⇒ 근거 칸(「卯 = 신부 공망」)과 ★말이 맞습니다 — 두 말이 아닙니다.
```

### ② 🔴 긴 설명을 «두 줄» 로 [대표님 「두 줄이나 세 줄로 나오면 되지 않을까」]

```
[왜]  요약은 12~16자짜리 «한 줄» 로 잡혀 있습니다 (굵게 14.5px).
      52자를 그대로 두면 ★굵은 글씨가 두 줄이 되어 «소리치는» 느낌이 됩니다.

[고침]  summaryOf 가 ★sub(뒷말) 을 따로 돌려줍니다
   첫 줄  「신부분께 공망(기운이 비는 자리)인 날이에요」   ★26자 · 굵게
          ⇒ 다른 갈래(「모나는 날」·「부딪히는 날」)와 ★굵기·길이가 맞습니다
   뒷줄  「힘이 실리지 않는 자리라, 큰일을 시작하는 날로는 피합니다.」
          ⇒ ★굵지 않게 · 12.5px · 한 칸 띄워서 · 조금 흐리게(opacity 0.8)
   ★keep-all — 낱말이 가운데서 잘리지 않습니다

⚠️ sub 칸은 ★다른 갈래에도 쓸 수 있습니다 (모나는 날 · 부딪히는 날).
   지금은 ★공망에만 붙였습니다. 필요하시면 그때 더하시면 됩니다.
```

### ③ 이사택일 — 「공망을 비켜갔어요」

```
[전]  「빈자리를 ★비껴갔어요」
[후]  「★공망을 비켜갔어요」
⚠️ ★«비키다» 가 맞습니다 — «피해서» 지나가는 것이기 때문입니다.
   (비스듬히 «스쳐» 지나가는 쪽 낱말과 헷갈리기 쉽습니다)
⇒ 충 설명의 「비껴갑니다」 도 ★「비켜갑니다」 로 함께 고쳤습니다.
⇒ 본문 「공망은 기운이 비는 자리예요」 는 ★그대로입니다 — 잘 되어 있었습니다.
```
