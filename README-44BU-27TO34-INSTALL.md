```
     손님 눈에 «어긋나» 보였습니다 (48% 도 F 로 갈립니다).
★[이제]  가운데가 «반반» 이고, 고른 쪽으로 자랍니다.
   ⇒ 막대와 진한 글자가 «언제나» 같은 쪽입니다. 짧으면 반반에 가깝다는 뜻입니다.
   ★44부 23차에 궁합 오행 그래프를 「가운데 0」으로 바꾼 것과 같은 결입니다.
★그리고 「아래 막대는 «사주로 본 결» 이에요」로 ★임자를 밝힙니다.
```

## ⚠️ 찍어 보고 네 번 고쳤습니다

```
🔴 「1가지가 갈립니다」        → ★「한 가지가」
🔴 「INFP(…) 라고 하셨지요」   → ★앞 빈칸 제거
🔴 「N 아직 없는 그림을 먼저 보는 결 / 아직 없는 그림을 먼저 봅니다」 ← ★같은 말 두 번
   ⇒ trimEcho() — 짧은 이름의 낱말이 겹치는 문장을 뺍니다
   ⚠️ 처음엔 «앞 여덟 글자» 로 견주었는데 S·J·P 를 못 잡았습니다
      (「정해 두고 가는 결」/「정해 두고 가야 편합니다」 — 말끝만 다릅니다)
      ⇒ ★낱말 기준으로 다시 짰습니다. 여덟 글자 모두 확인했습니다.
🔴 옛 「타고난 결 ↔ 지금의 결」 상자  → ★걷어냈습니다. 같은 말을 «세 번» 하고 있었습니다
```

## ⚠️ 검사 다섯을 «뜻 그대로» 고쳤습니다

앞 차수 그물이 «옛 모양» 을 글자로 지키고 있어 걸렸습니다. **헐겁게 하지 않았습니다.**

```
「width: ${a.leftPct}%」      → ★「${a.leftPct - 50}% / ${50 - a.leftPct}%」 (가운데 기준)
「어떤 결인가요」가 있는가      → ★「이긴 글자의 설명을 그리는가」 (자리를 옮겼을 뿐)
「) : null}」이 있는가         → ★「넣으라고 조르는 말이 «없는가»」 (본디 재려던 것)
```

★**역시험을 두 번 했습니다** — 여는말을 바꾸고, 같은 결 설명을 지워 보니 둘 다 잡았습니다.
