# ★검사 ㉔㉕ 신설

```
㉔  진로적성 용신이 «치환한 점수» 로 나오는가
      · 그 사주가 「신강」·「火」로 나오는가 (극신약·木이면 안 고쳐진 것)
      · ★오각형(진로 점수)의 신강약과 «같은 답» 인가   ← 이 그물의 알맹이
      · 「겁재」로 좁혀 말하지 않는가
      · ⛔ yongsinNew 의 기본값이 «본래 오행» 그대로인가 (안 건드렸는가)
      · ⚠️ 궁합이 «그대로» 인가

㉕  궁합의 진술축미가 «조후용신» 으로 반영되는가
      丑월 → 火 (겨울생) · 未월 → 水 (여름생)
      ⚠️ 辰·戌은 «교재에 없음» → 「조후 없음」. 지어내지 않습니다
```

★**㉕는 교재 확인으로 «맞는 것을 못 박은» 것** 입니다. 궁합은 고칠 것이
없었습니다 — 점수는 오행 그대로, 계절은 조후용신이 맡고 있었습니다.
