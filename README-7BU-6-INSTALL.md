## 2. 🔴 고친 것 셋 — ★셋 다 «제가 만든 것» 입니다

### ① 🔴 사주 용어를 «말로만» 막아 안 지켜졌습니다

```
[지시문에 적은 것]  「사주 용어는 한 갈래에 ★한 개까지」
[실제로 나온 것]
   1번 갈래  직장운 · 타고난 그릇 ×3
   2번 갈래  직책운 ×2 · ★짜임 ×2 · ★말하고 글로 설득하는 힘
   3번 갈래  직장·합격운 ×2 · ★말하고 글 쓰는 재주 · 남과 견주는 마음
   4번 갈래  ★0개  ✅ (여기만 지켜졌습니다)
⇒ 🔴 ★6부 0장과 «같은 교훈» 입니다 — 「말」 이 아니라 ★「값」 으로 세야 합니다.

[고침]  ★promoTidy() — 글을 «받은 뒤» 에 값으로 다듬습니다
   · PROMO_SWAP      금지어를 ★언제나 생활 말로
        「말하고 글 쓰는 재주」 → 「말과 글로 풀어내는 솜씨」
        「남과 견주는 마음」   → 「옆을 살피게 되는 마음」
        「짜임」 → 「바탕」 · 「자리가 나를 부르는 흐름」 → 「자리가 열리는 때」
   · PROMO_TERM_ONCE  갈래마다 ★첫 번째만 남기고 그다음은 받아 쓰는 말로
        직책운 · 직장운 · 직장·합격운 → 두 번째부터 ★「그 힘」
        타고난 그릇 → 두 번째부터 ★「본래 바탕」
   · cheer(4번 갈래) 는 ★한 개도 안 둡니다
⚠️ 글자를 «지우지» 않고 ★«바꿉니다». 문장이 무너지지 않게 하려는 것입니다.
⚠️ 승진에서만 돕니다 — 합격운 · 취업운은 ★그대로입니다.
```
