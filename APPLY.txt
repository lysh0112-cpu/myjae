서비스마다 무엇을 꺼내는가
------------------------------------------------------------------
  사주보기/대운/세운
      손님이 고른 질문의 대분류(19개)로 고릅니다.
      건강 -> 오행 건강줄·충의 장부·개운법
      연애 -> 합·충·도화 / 진로 -> 살·직업 / 인간관계 -> 다루는 법
      실측: 질문 없음 348자 ~ 넷을 한꺼번에 1,330자

  궁합
      사람마다 일간 3줄 + 오행 과다·결핍 + ★다루는 법 + 합충
      ★성별 줄은 넘기지 않습니다.
        상대방 사주에 "여자 金은 살림을 잘합니다" 가 뜨면 곤란합니다.
      ★"다루는 법"(교재 20~24쪽)이 여기서 가장 값집니다.
        다른 자료는 "그 사람이 어떤가" 인데 이것만 "어떻게 대할 것인가" 입니다.

  진로적성
      카드마다 나눠 얹습니다. 대목을 새로 만들지 않았습니다.
        [일주가 말하는 것] <- 일간 4줄 (교재 41~47쪽)
        [타고난 신살]      <- 살 (교재 94~97쪽)
        [어울리는 직업]    <- 살 + 교재가 든 직업

  합격운
      학문에 닿는 살만 골라 얹습니다 (문창성·천을귀인·현침살).
      재료 뒤에 사실로만 붙이고 대목을 새로 만들지 않았습니다.

  물상
      [그림 주인공] 블록에 교재 41쪽 물상과 25쪽 계절·색·맛을 얹습니다.
      물상도는 "무엇에 빗대는가" 가 알맹이라 교재 41쪽이 그대로 쓰입니다.

  연월운세

돌려 보고 고친 사고 넷
------------------------------------------------------------------
타입검사로는 안 잡히는 것들이라 실제로 돌려서 찾았습니다.

  1. 양인살을 일주 간지로 잡고 있었습니다 -> 교재는 일간 기준 월지
  2. 현침살을 2개로 잡았습니다 -> 교재는 3개 이상 또는 일주 현침
  3. 도화살이 뜻이 아니라 판정 조건을 내보냈습니다
     "3개 이상 있으면 작용력이 셉니다" 가 재료로 나갔습니다.
     AI 에게 줄 것은 뜻이지 잣대가 아닙니다.
  4. 물상에서 변수만 만들고 프롬프트에 안 넣었습니다 (교훈 BN 그대로)
     bookImage / bookStage 를 선언만 하고 안 썼습니다. 넣었습니다.
