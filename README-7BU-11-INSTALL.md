## 1. 🔴🔴 연도가 틀렸습니다

```
[나온 글]  「★올해 2025년 과 내년 2026년, 두 해를 함께 보겠습니다」
           ⇒ 바로 다음 줄은 「2026년은 보통인 해입니다」 — ★스스로 어긋났습니다.
[까닭]  값(thisYear = 2026)은 ★제대로 갔습니다. 달별 재료에도 「2026년 9월」 이 있었습니다.
        ⇒ 그런데 AI 가 ★«자기가 배운 시절» 을 올해로 여겼습니다.
        ⚠️ 제 잘못도 하나 — 연도를 ★«재료 속» 에만 두고 «맨 앞» 에 안 박았습니다.
[왜 아픈가]  연도를 틀리면 ★글 «전체» 가 의심받습니다.

[고침 둘]
   ① 지시문 ★«맨 앞» 에 — 「★올해는 «2026년» 입니다. 내년은 «2027년» 입니다.
      ⛔다른 해를 «올해» 라고 쓰지 마세요. 연도를 지어내지 마세요」
   ② ★fixPromoYear() — 나온 뒤에도 값으로 바로잡습니다
      「올해 2025년」 → ★「올해 2026년」 · 「내년 2026년」 → ★「내년 2027년」
      ⚠️ 「올해」 가 안 붙은 연도는 ★안 건드립니다 (다른 규칙이 봅니다)
```

## 2. 🔴 「내년 … 10월」 이 또 나왔습니다

```
[나온 글]  「내년 ★인사 발표 시기인 10월 언저리 도…」
           「내년 ★인사 발표 앞뒤인 10월 언저리 에도…」
[까닭]  앞판 규칙은 「내년 10월」 처럼 ★«붙어 있을 때» 만 잡았습니다.
        사이에 말이 끼면 못 잡았습니다.
[고침]  ★dropNextYearMonthWord() — ★한 문장 안에서 «내년» 뒤의 달을 봅니다.
   「내년 인사 발표 시기인 10월 언저리도」 → ★「내년 인사 발표 시기도」
   「내년 인사 발표 앞뒤인 10월 언저리에도」 → ★「내년 인사 발표 앞뒤에도」
   「내년 10월 언저리는」 → ★「내년 같은 시기는」
⚠️ ★올해 달은 그대로 둡니다 — 지금 하실 일이 거기 있습니다.
⚠️ 만들다 「시기인 ★같은 시기」 처럼 말이 겹친 것을 시험해 보고 잡았습니다.
```

## 3. 🔴 한 단락 «안» 에서 말이 뒤집혔습니다

```
[나온 글]  「지금 시간을 쓰면 ★오히려 늦는 일이 있습니다. …간담회 같은 자리가 그것입니다」
           「그 자리에서 직접 말하는 것이 ★서류보다 먼저 인상을 남깁니다」
⇒ ★«하지 말라» 해 놓고 «그게 낫다» 고 합니다. 손님이 헷갈립니다.

[까닭]  제가 ★「지금 손대면 시간만 쓰는 일도 하나 짚으세요」 라고
        ★AI 에게 «고르게» 했습니다. 고르다 마음이 바뀝니다.
[고침]  ★우리가 «정해서» 줍니다 —
   「새로운 분야를 새로 공부하거나, 지금 자리와 이어지지 않는 자격을 더하는 것」
   ⛔다른 것을 고르지 마세요 · ⛔말을 뒤집지 마세요 ·
   ⛔보고 · 발표를 «하지 말라» 고 쓰지 마세요 — ★그건 10월에 하실 일입니다.
⇒ 6부에서 유형 · 좋은 달 · 당일 수칙을 ★엔진이 정하게 바꾼 것과 «같은 일» 입니다.
```
