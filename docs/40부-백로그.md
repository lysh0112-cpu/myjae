## 무엇이 문제인가

화면 한 카드 안에서 이렇게 됩니다.


## ★40부에 «근거» 가 생겼습니다

> 「상생을 하는 것은 좋고 상극을 하는 관계는 나쁘다고 할 수 없다.
>  … 화 오행이 과다한데 화를 상생해 주는 목이 와서 목생화를 하면 …

## 3-1. 竣 획수 확인 ★바로

```

★확인할 것
  ① 손님이 竣 을 고르려다 踆 을 고른 것인가 (UX)
  ② DB 의 竣 줄이 12획으로 들어 있는가        ← 이쪽이면 교훈 EQ
```

**영향** — 두 글자는 사격 넷 중 **셋이 달라집니다.**

```
竣 12획   24 출세격     · 21 자립격 · 21 자립격 · 33 등용격
```
