## 3. 🔴 ② 결과표가 나오기 «직전» 에 AI 가격표 [대표님]

```
[보기] 단추를 누르면 → ★결제 시트가 «먼저» 뜹니다
   ⇒ 진로적성 · 사주그림 · 타로와 ★«같은 모양» 입니다 [대표님 6부 「통일시켜야」]
   ⇒ 시트에서 한 번 더 누르셔야 결과로 갑니다

★셋이 각각 다른 시트를 보입니다 —
   합격운 분석  「시험과 합격의 흐름을 사주로 짚어 드려요」
   취업운 분석  「일자리와 이직의 흐름을 사주로 짚어 드려요」
   승진운 분석  「지금 자리에서 다음 자리로 가는 길을 사주로 짚어 드려요」
   ⇒ 담긴 것 세 줄도 각각 다릅니다.

⛔ 브라우저 confirm 을 쓰지 않습니다 — 아홉 화면과 결이 달라집니다.
⚠️ 시트는 ★«묻기만» 합니다. 실제 차감은 ★AI 가 돌기 직전에 합니다.
```

## 4. 🔴 ③ 결과표 하단에 전문상담사 연결 [대표님]

