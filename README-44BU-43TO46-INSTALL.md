# 🔴 46차 — 「근거 보기」를 감췄습니다 (대표님 지시)

## 무엇이 나가고 있었나

펼쳐 보이던 것은 ★**교재 원문 그대로의 판정 문장**입니다.

```
⚠️ 명리 술어가 날것으로 — 식상 · 격국용신 · 활인업 · 현침살 · 도화살
🔴 그보다 무거운 것은 ★«단정하는 험한 말» 입니다 —
   「독선적이고 융통성이 부족하며 자존심과 집착이 강해요」
   「남을 배려하는 마음이 부족하고 … 대인 관계가 매끄럽지 못한 편입니다」
   「변덕이 있고 비밀을 발설하며 … 구설수가 따릅니다」
★14세 손님과 부모님이 «함께» 읽습니다.
```

★AI 풀이는 같은 내용을 **「장점이 넘쳐서 오히려 걸림돌이 될 때가 있습니다」**로
다듬어 전합니다. **다듬은 말이 이미 있는데 날것을 곁들일 까닭이 없습니다.**

```
const SHOW_WHY = false    ← ★한 곳
```

⚠️⚠️ **「지운」 것이 아니라 «감춘» 것입니다** — `card.lines` 도 `openWhy` 도 그대로입니다.
★**되살리시려면 그 한 줄을 true 로** 두십시오.

## ⚠️ 합격운은 «건드리지 않았습니다»

같은 꼴의 「근거 보기」가 있지만, **그쪽 판정 문장은 이미 다듬어진 말**입니다 —
「인성(배움의 기운)이 더 중요합니다」처럼 술어에 풀이가 붙어 있고 험한 말이 없습니다.
★**멀쩡한 것을 함께 끄지 않았습니다.**
