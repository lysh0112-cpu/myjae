## ★무엇이 달라지나

### 1. 상담사 만세력 창에 넷째 탭

```
[🔮 만세력]  [📖 원본 해설]  [⚖️ 용신]  [🌿 물상]
             ★넷이 «같은 입력칸» 을 씁니다. 한 번 넣으면 넷 다 바로 봅니다.
```

생년월일·시·성별·양력음력을 넣으면 **교재 원문이 그대로** 펼쳐집니다 —
물상 낱말 · 개관 · 좋아하는/싫어하는 天干 · 天干論(원국에 있는 천간만) · 地支論(걸린 계절) · 通辯論 사례.

⚠️ **甲木·乙木 일간만** 나옵니다. 나머지 여덟 일간은 화면이
「이 장은 아직 안 담겼습니다」라고 알려 줍니다. 스캔을 주시면 채웁니다.

### 2. 궁합에서 「소무승 물상론」 이름이 사라짐

글 길이는 그대로입니다(65자만 줄었습니다). 출전 이름만 걷어냈습니다.

```
[전]  …자연스레 무장해제됩니다.  소무승 물상론에서는 이를 쩍쩍 갈라진 사막 벌판(己土)…
[후]  …자연스레 무장해제됩니다.  물상으로 보면 이를 쩍쩍 갈라진 사막 벌판(己土)…
```

### 3. 손님 화면은 «하나도» 안 바뀝니다

물상 탭은 상담사 전용입니다. 「내 사주그림」도 그대로입니다.

## ⛔ 손대실 때 조심할 것

```
⛔⛔ ★⚖️ 용신 탭과 답이 «달라도» 어긋난 것이 아닙니다 [연재쌤].
     기존 파이프라인 : 원국을 «재어서» 좋고 싫음을 정합니다
     물상론          : 일간이 정해지는 «순간» 이미 정해져 있습니다
     ⇒ 화면 아래 안내문이 그 말을 합니다. ★그 안내문을 지우지 마십시오.

⛔⛔ ★lib/saju/mulsangData.ts 를 교재에 맞춰 «고치지» 마십시오.
     그 파일에도 「소무승 물상론」이라 적혀 있으나 ★교재 원문이 아닙니다.
     손님 그림 해설용으로 추려 다듬은 것입니다.
     예) 교재 017쪽 甲木 「싫어하는 天干 : 乙, 己, 辛」
         mulsangData RELATION.甲 「乙 · 辛 · 癸」   ← ★오류가 «아닙니다»

⛔⛔ ★교재 원문 그대로라 «거친 말» 이 나옵니다 —
     「집에서 못 죽고 객사한다」·「망한 집안 출신이다」·「90% 이상 이혼」 …
     ⇒ 상담사가 보고 «가려서» 유선으로 전하시는 자리입니다.
     ⛔ 손님 화면으로 옮기지 마십시오.
     ⚠️ 손님 쪽으로 보낼 때는 ★readSomu({ forCustomer: true }) 를 쓰면
        '상담사만' 줄과 通辯論 사례가 «통째로» 빠집니다 (이미 되어 있습니다).

⛔ ★통변론(通辯論) 사례는 교재에 실린 «남의 사주» 입니다.
   이 손님 것이 아닙니다. 계절이 맞는 것을 위로 올려 두었습니다.
```
