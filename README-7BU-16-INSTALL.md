## 2. 고침 — 애니메이션은 지키면서

```
⚠️ maxHeight 는 ★«펴는 움직임» 때문에 둔 것입니다. 그냥 없애면 움직임이 깨집니다.

[고침]
   여는 «동안»   maxHeight 2000px  ⇒ ★움직임이 그대로 보입니다
   다 펴진 «뒤»  maxHeight ★'none' · overflow ★'visible'
                 ⇒ ★내용이 아무리 길어도 «안 잘립니다»
   접히면        ★다시 잠급니다 (접는 모습도 그대로)

⚠️ onTransitionEnd — «움직임이 끝난 뒤» 에 푸는 방식입니다.
⚠️ effect 안에서 setState 를 부르지 «않았습니다» — 린트가 막는 자리입니다.
   ⇒ const settled = isOpen && settledRaw  로 풀었습니다.
```

### ⛔ 바깥 상자는 «건드리지 않았습니다»

```
바깥 상자에도 overflow:hidden 이 있습니다.
⇒ ★그건 «둥근 모서리(borderRadius 16px)» 를 깎으려고 둔 것입니다. 높이는 안 자릅니다.
⇒ ⛔ 그 자리를 지우면 ★모서리가 각지게 됩니다.
```
