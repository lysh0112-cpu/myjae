# ★검사 ㉜ 신설

```
· 일지가 午 → 1개인데도 «작용» 하는가 (개수 무관)
· 甲午 → 일간·일지 둘 다 현침인가
· ⚠️ 甲子 → 일«간» 만 현침이면 «성립 안 함» (일지 기준이므로)
· 일주 아닌 곳에 셋 → «개수» 로 작용하는가 (「이거나」의 앞쪽)
· ⚠️ strongAt 을 썼고 needAt 은 «안» 썼는가
· ⚠️ 「교재 근거가 아니다」가 코드에 적혀 있는가
· 🔴 겹침 제거가 «묶음에만» 걸리는가 (글자 신살까지 자르면 안 됨)
```
