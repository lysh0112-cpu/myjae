⚠️ **제가 이번에 밟은 것 둘** —

**둘째.** 배너 그물에 **느슨한 가지(`|| …`)**를 두었다가,
줄바꿈을 없애는 되살림 시험에서 **안 잡혔습니다.** 가지를 걷어내고 다시 시험했습니다.
⇒ 9부 ② 「되살려 보지 않은 그물은 그물이 아닙니다」 그대로입니다.

**첫째.** 검사 57 에 ⑤번을 더하면서
**끝맺음 줄(`통과 N · 실패 N` · `process.exit(1)`)을 실수로 지웠습니다.**
그 상태로 되살림 시험을 한 번 돌렸는데 **아무것도 안 잡혔습니다.**
⇒ 되살려 놓고 **결과가 «안 나오는» 것**을 보고서야 알았습니다.
⇒ 🔴 **9부 교훈 그대로입니다** — 되살려 시험한 뒤에는 **그물이 살아 있는지도** 보십시오.
