## 1. 대표님이 «본인 사주» 를 읽고 찾아내신 것

```
[대표님]  「위 아래가 ★상호 모순되지 않니?」

대표님 사주 — 壬(수) 일간 · 수 55 과다 · 토 25 발달
   「비겁과 관성이 ★강점 지능입니다」
   「독립심과 경쟁심과 승부욕이 강해요 … ★추진력과 결단력이 있습니다」
   「수 비겁 — 생각은 많은데 ★실천력이 부족해요」
⇒ 🔴 ★같은 비겁을 두고 «추진력 있다» 와 «실천력 부족» 이 나란히 났습니다.
```

## 2. 🔴 까닭 — 교재가 «두 층» 으로 말합니다

```
교재 79쪽      비겁이라는 ★«묶음» 의 일반 성질
               「독립심과 경쟁심 … 추진력과 결단력이 있습니다」
교재 82~89쪽   그 비겁이 ★«어느 오행» 으로 나타나는가 (25칸 격자)
               비겁 × 수 — 「생각은 많은데 ★실천력이 부족해요」

⇒ 화면이 ★«둘 다» 그대로 내보냈습니다.
⇒ ⚠️ 교재 165쪽 — 「★오행과 육친의 강점 지능에서 진로적성을 찾는다」
   ⇒ 교재도 ★«오행 × 육친» 을 본체로 봅니다. 79쪽은 묶음 설명입니다.

★25칸을 재어 보니 ★어긋나는 칸이 셋이었습니다 —
   비겁 × 수  ·  재성 × 수  ·  식상 × 금
```

## 4. ★대표님과 «하나씩 대조해» 다시 쓴 일곱 칸

```
① 비겁 × 화
  [원문] 성급하고 … 여유가 없고 융통성이 부족한 편이며, 한자리에서 오래 하는 연구직은 맞지 않습니다.
  [지금] 결단이 빠르고 … 한자리에 오래 머무는 일보다 ★손과 몸으로 바로 결과를 내는 일에서 힘이 납니다.
  ⚠️ ★교재가 붙여 둔 직업(의사·이미용·스포츠·운전·기계·철물)에서 끌어냈습니다.
     제가 처음 「사람과 부딪히며」 라 썼다가 ★교재 직업과 안 맞아 고쳤습니다.

② 비겁 × 토
  [원문] 목이나 금이 없으면 ★고집불통이 됩니다. 맡은 일에 ★집착이 많고 …
  [지금] 맡은 일을 ★끝까지 붙잡는 힘이 크고 … 장인 기질입니다.
         다만 목이나 금이 곁에 없으면 ★한번 정한 생각을 잘 안 바꾸시는 편입니다.

③ 비겁 × 수   ← ★대표님 자리
  [원문] 생각은 많은데 ★실천력이 부족해요. 쉽게 피곤하고 … 평정심을 잃고 출렁이기 쉽습니다.
  [지금] ★매사 많은 것을 고려하고, 실천으로 옮기는 데 신중함이 큽니다.
         그래서 꼼꼼히 따지고 재야 하는 일에서 강점이 있습니다.
         또한 앞을 내다보는 예지력이 강한 편입니다.
  ⚠️ 「마음이 출렁일 때가 있습니다」 를 제가 냈다가 ★「생뚱맞다」 하셔서 뺐습니다.

④ 식상 × 목
  [원문] … 추진력은 좋으나 마무리가 부족한 ★용두사미 타입입니다.
  [지금] … 시작하는 힘이 좋아 새로 벌이고 알리는 일에서 강점이 있습니다.
         한편으로는 관심이 넓어 계속 새로운 일을 찾아 나서는 경향이 있습니다.
         ★벌여 둔 것을 한 번씩 거두는 시간을 두시면 더 크게 갈 수 있습니다.

⑤ 재성 × 수   ← ★가장 셌던 칸 (흠만 셋)
  [원문] … ★의심이 많고 겁이 많아 … ★우울해질 수 있으니 마음공부가 도움이 됩니다.
  [지금] 생각이 깊고 원칙을 지키는 편이라 쉽게 넘어가지 않습니다.
         ★살펴보는 눈이 밝아 큰일일수록 재고 또 재신 뒤에 움직이십니다.
         그래서 큰돈과 큰 거래를 다루는 일에서 강점이 있습니다.
         다만 재는 일이 길어지면 ★마음이 지치기 쉬우니, 마음을 적절히 다스리는 시간을 두시면 좋습니다.
  ⚠️ ★「우울」 이라는 병 이름을 안 씁니다 (sinsal.ts 원칙 그대로).
     대신 교재가 준 «마음공부» 길은 ★「마음을 적절히 다스리는」 으로 살렸습니다.

⑥ 인성 × 토
  [원문] … ★잠이 많고 게으른 편이라 부지런함을 길러야 합니다.
  [지금] … 서둘러 뛰어다니기보다 ★한자리에서 오래 들여다보는 결이라,
         깊이 봐야 하는 일에서 강점이 있습니다.
  ★[덧붙임]  「일부 사주명리 분석에서는 잠이 많아 게으른 편으로 보고,
              스스로 조금은 부지런함을 키울 필요가 있다고도 해석합니다.」
  🔴 ★이 «덧붙임» 틀은 대표님이 만들어 주신 것입니다 —
     교재를 안 버리면서 «한 갈래의 견해» 로 가려서 전합니다.
     ⇒ 일곱 칸 중 ★이 칸에만 넣었습니다 [대표님].

⑦ 인성 × 수
  [원문] … ★숫기가 부족해 낯선 곳에 적응하는 힘이 약한 편입니다.
  [지금] 품이 넓고 남을 이해하는 마음이 크지만, 말이나 행동으로 굳이 드러내지 않아요.
         ★낯선 자리일수록 먼저 살피고 천천히 다가가는 편입니다.
         그래서 한자리에서 오래 파고드는 일에서 강점이 있습니다.
```

## 5. 🔴 「과다」 를 어떻게 부르는지 — ★대표님이 바로잡아 주셨습니다

```
[제가 하려던 것]  과다를 ★«강점 지능» 에서 «뺀다» → 「가장 크게 타고난 결」
[대표님]  「과다는 ★강점이기는 하지만 단점으로 작용할 수도 있으니 ★주의해야 한다」
⇒ ⚠️ ★제가 지나쳤습니다. 강점인 것을 아니라고 한 셈이었습니다.

[지금]
  · ★「강점 지능」 이라는 말은 «그대로» 둡니다
  · 과다 줄에 ★「강점이기는 하지만 장점이 넘쳐 단점으로 나타날 수도 있으니
    살펴 두시면 좋습니다」 를 붙입니다
  · ⛔ 과다일 때만 ★79쪽 «묶음 강점 설명» 을 안 붙입니다
    (바로 아래 오행별 칸과 어긋나던 자리입니다)
```
