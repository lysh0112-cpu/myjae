## 1. 대표님이 실제 통변을 읽고 찾아내신 것

### ① 🔴 제목이 «취업운 것» 그대로였습니다

```
[나온 것]                            [고친 것]
🧬 1. 한눈에 보는 나의 흐름과 강점   →  🧬 1. ★지금 자리에서의 나
🎯 2. ★«합격과 성취를 위한» 실전 전략 →  🚪 2. ★다음 자리로 가는 길
🗓️ 3. 월별 페이스메이커와 ★«D-Day» 수칙 → 🗓️ 3. ★올해와 내년 · 인사 시기에 맞춘 달
💌 4. 마지막 응원과 오늘의 실천      →  그대로 (이건 맞았습니다)

[까닭]  제가 PROMO_SECTIONS 를 ★«표에만» 만들고 «화면에 안 이었습니다».
        제목은 buildExamSeven 의 sevenOf() 가 정하는데, 승진을 몰랐습니다.
[고침]  ★SEVEN_PROMO 표를 만들고 sevenOf(target, ★promo) 로 갈랐습니다.
⚠️ 「D-Day」 는 승진에 ★없는 말입니다 — 날짜는 «회사가» 정합니다.
⚠️ 「합격과 성취」 도 아닙니다 — 승진은 합격·불합격이 아닙니다.
⛔ 옛 기록(legacy)은 ★그대로 옛 제목으로 열립니다. 안 깨집니다.
```

### ② 🔴 연표가 «다섯 해» 였습니다 (2026 ~ 2030)

```
[정하신 것]  연재쌤·대표님 — 「★올해와 내년 «두 해» 까지만」
[제가 한 것] 지시문에만 넣고 ★«화면 연표» 를 안 막았습니다 — 또 «절반» 입니다.
[고침]      YearStrip 이 maxYears 를 받습니다. 승진이면 ★2.
```

### ③ 🔴 «취업 지원» 이야기가 그대로 섞였습니다

```
[나온 글]
   「지원 안배는 조건이 잘 맞는 자리를 가장 많이 두시고 나머지를 나눠…」
   「★한 자리만 바라보고 모든 것을 거는 방식보다 몇 갈래를 나란히…」
⇒ 🔴 이건 ★«취업 지원» 이야기입니다. 승진은 ★바라보는 자리가 «하나» 입니다.
   엔진의 plan(지원 안배 · 전형 · 시간 배분)이 그대로 실려 갔습니다.
[고침]  planBlock(plan, section, ★promo) — 승진이면 셋을 «빼고»
        대신 ★「바라보는 자리가 하나입니다 · 다음 자리가 요구하는 것을 쓰세요」 를 넣습니다.
```

```

말씀드렸는데, ★값으로 보니 «버그가 아니었습니다».
⇒ 그것은 ★교재 맺음말 상자입니다 — 교재 195쪽 「흉할 것도 길할 것도 없다」.
```
