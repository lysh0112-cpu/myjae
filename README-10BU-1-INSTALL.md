## ② 리포트 내용과 하단이 겹치던 것

**하단의 자리별 카드 넷 + 운시 카드**를 통째로 걷어냈습니다.
리포트 줄의 **`자세히 ›`** 를 누르면 모달로 열립니다. 운시 줄도 리포트에 새로 넣었습니다.

옛 카드에만 있던 것은 **모달이 다 물려받았습니다** —
자리 뜻 · 신궁 한자 · 딴이름 · 통변(lead) · 사례 **세 줄**(쪽수·일진) ·
「태어난 시를 몰라 시지를 보지 않았어요」 · 「교재에 이 신궁의 «자리별» 풀이는 없습니다」

```
리포트  사례 ★두 줄   — «훑는» 자리
모달    사례 ★세 줄   — «짚는» 자리
```

⛔ 하단 카드를 다시 만들지 마십시오. 만들면 또 두 벌이 됩니다.

## ③ 열두 지지 표 — 위치가 맞느냐, 사람마다 다르냐

🔴 **사람마다 다르지 않습니다.**

생년월일·시·성별을 **한 글자도** 안 씁니다.
⇒ **같은 날 오신 분은 열두 칸이 모두 똑같습니다.**

그러니 이건 「손님 풀이」가 아니라 **그날의 범례**입니다.
⇒ 맨 아래에서 **문점일 칸 안**으로 올렸습니다.
⇒ 화면이 직접 그렇게 말합니다 — 「문점일 하나로 정해집니다. 같은 날 오신 분은 모두 같아요」
⇒ 손님의 네 자리는 **진한 칸**으로 표시하고, 그 아래 `연지·일지` 처럼 어느 자리인지 적었습니다.

⚠️ 시를 모르시면 `data.hits` 에서 가져오므로 **시지가 저절로 빠집니다**
(사주 문자열을 쪼갰으면 없는 시지를 표시할 뻔했습니다).
