## 무엇이 있었나

2026-07-30 실기기 확인에서 드러났습니다.

```
1998-01-05 壬일간 · 柳度伊
  계산  용신 목 · 희신 화 · 기신 금 · 수 과다(70) · 목 0점 · 금 0점
  재료  「비어 있는 기운  금 — 이름이 채우지 않았습니다」
        ★«금이 기신» 이라는 말이 재료에 없었습니다
  결과  AI 가 좋은 뜻으로 —
        「살아가며 금의 기운을 의식적으로 가꾸어 나가는 방향으로…」
        → 꺼려야 할 기운을 «가꾸라» 고 권했습니다
```

까닭 — 기신·구신을 **«이름에 들어 있을 때만»** 재료에 적고 있었습니다.
사주 자체의 기신은 AI 에게 알려 주지 않았습니다.

## 고친 것 셋

```
① 기신·구신을 «언제나» 재료에 적습니다 (이름에 없어도)
② 채우지 않은 결핍을 «바라는 기운» 과 «꺼리는 기운» 으로 갈라 적습니다
     비어 있는 기운           목 — 이름이 채우지 않았습니다
     비어 있으나 꺼리는 기운   금 — 비어 있는 것이 편한 자리로 봅니다
③ 기신·구신이 결핍이어도 채우면 «가산하지 않습니다»
   (꺼리는 기운이 비어 있는 것은 아쉬움이 아니라 편한 자리입니다)
+  프롬프트에 「기신·구신을 채우라·가꾸라 고 권하지 마세요」 를 명시했습니다
```

## ⚠️ 판정이 «좋아지는» 고침이 아닙니다

柳度伊 는 고침 전후 모두 경고 0건이고 좋은 이름입니다(용신 목 충족 · 목 결핍 보충).
바뀌는 것은 **AI 가 기신을 잘못 권하지 않게 되는 것**입니다.
